プライバシーポリシー

ハビットモンスター（個人用の習慣トラッカー）　最終更新：2026年10月14日

1. 取得する情報

利用者が Google アカウントで許可したときだけ、次の情報を読み込みます。

  • Google カレンダーの予定（タイトル・日時・色。読み取りのみ）
  • Google ToDo リストの ToDo（タイトル・期限・完了したか）

2. 使い方

  • 予定と ToDo を、アプリの「やること」として表示するためだけに使います。
  • アプリでやることを完了にしたとき、その ToDo を Google ToDo リストでも完了にします。カレンダーの予定は書きかえません。
  • やることのタイトルから、難しさ（もらえる経験値）を判定するために、タイトルの文字だけを OpenAI の API に送ることがあります。OpenAI の API に送ったデータは、OpenAI のモデルの学習には使われません。

3. 保存と共有

  • 読み込んだ内容と、Google のログイン情報（アクセス用の鍵）は、利用者自身のパソコンの中だけに保存します。作者のサーバーには送りません。
  • 第三者に販売・提供したり、広告に使ったりすることはありません。
  • Google から受け取った情報の扱いは、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

4. 削除のしかた

  • Google アカウントの「サードパーティ製のアプリとサービス」から、このアプリへのアクセスをいつでも取り消せます。
  • パソコンの中のログイン情報（secrets フォルダ）とセーブデータを消すと、読み込んだ内容も消えます。

5. 変更

このポリシーを変えるときは、このページを更新します。

6. 連絡先

このアプリは、作者が自分のために作った個人用のアプリです。お問い合わせは、Google の同意画面に表示される デベロッパーの連絡先へお願いします。

Privacy Policy (English summary)

Habit Monster reads Google Calendar events (read-only) and Google Tasks only after the user grants access, and uses them only to show the user's to-dos in the app. When the user completes a to-do in the app, the matching task is marked complete in Google Tasks. Calendar events are never modified. Task titles may be sent to the OpenAI API to judge their difficulty; data sent to the OpenAI API is not used to train OpenAI models. All data and the Google access token are stored only on the user's own computer, never on the developer's server, and are never sold, shared, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account "Third-party apps & services" page.
